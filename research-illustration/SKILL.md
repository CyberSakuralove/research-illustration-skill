# 插画式科研展示图

将研究内容变成能用于论文或 PPT 的一张展示图：彩色分区、清楚的关系、内部有细节的具体对象和紧凑的图形结构。以用户参考和科学含义共同决定画法，不沿用方框流程模板。

默认风格以用户已认可的 [LEV 展示样张](assets/approved-lev-example.png) 为对照：短标签、充实的图形信息、协调的彩色分区、统一轮廓和有内部结构的对象。它是画法示例，不是其他论文的内容或布局模板。

## 内容与构图

- 先阅读用户指定的论文、代码或材料，核对核心机制、对象含义、数据/控制方向和关键边界。区分已验证结果与设计设想；不替研究补造效果或机制。缺失信息只有在影响科学含义时才追问，其余采用可说明的合理假设。
- 把核心机制转为可见对象、分组、关系和结果变化。按语义选文档、代码片段、节点网络、仪表、样本集合等对象，并用其内部结构表达作用；不靠装饰图标凑密度。共享、迭代、筛选和结果差异尽量通过重复对象、连接和局部变化直接呈现。
- 标签短而明确，留给展示时阅读。不要把公式、推导或大段解释默认搬到图上；仅在用户需要时保留关键公式。图外也不默认附长报告。
- 信息密度来自分组、重复对象、局部细节、连线和层级。避免大片无作用空白，也避免挤压标签；不设图标数量下限、方框数量上限或字数 KPI。颜色和边框服务于分区与对象辨识，允许丰富配色和必要的框，不把“颜色乱、框堆砌”改写成白底少色或禁止框。
- 大区使用协调的浅色底，具体对象保留明确的局部颜色；轮廓、文字和箭头形成统一的深色骨架。同一对象跨区保持身份一致，不给每个模块随意换一套颜色或图标画法。
- 面积随内容安排，主机制形成紧凑连续路径，必要的训练过程、候选组或实例围绕它组织。分区内同时消除局部挤压与无作用空白，不强行等分，也不为填满固定区域而拉开节点。
- 内容决定布局和图的数量。默认只交付用户要的一张图，不自动拆成多张，也不把某篇论文的布局固定为通用答案。

## 参考与生成

1. 阅读 [reference-guide.md](references/reference-guide.md)，并实际查看将使用的参考图。用户有新参考时以其要求为准；默认以 `assets/approved-lev-example.png` 为已认可风格锚点，原始主参考为 `assets/reference-hierarchical-gate.png`，辅助参考为 `assets/reference-sketch-alternation.png`。
2. 使用内置示例时，在 prompt 中分别写明：LEV 样张提供已经用户认可的整体画法；原始主参考提供彩色分区、统一黑色轮廓、具体对象内部细节与整体密度；辅参考提供同一对象配色一致、成组候选/读出与外围循环的画法。按当前图的需要选择参考，用户提供新参考时重新指定作用。仅迁移视觉语法，不复制原图的研究标签、结论或布局拓扑。
3. 首选当前可用、适合参考图驱动插画生成的 `image_gen` 后端，遵循其实际调用规范。把选定参考作为真正的图像输入；本地图用 `referenced_image_paths`，只有目标图缺少本地路径时才按工具规范使用近期会话图像。不能只在 prompt 中写文件名或声称“参考了”未传入的图。
4. prompt 同时给出已核对的研究内容、对象与关系、精确短标签、画布用途，以及主/辅参考各自的作用。内置 `image_gen` 可直接调用，不需要用户配置 API key，也不转到 CLI。若当前不可用，先查现有能力并如实说明限制，不把其他工具的能力说成已验证。

## 看图、修订与交付

- 每次生成后实际查看图片，在目标展示尺寸检查：科学含义与关键边界；标签错字和可读性；箭头起终点及方向；同一对象的形状/配色一致性；图形密度、留白和主参考风格。发现问题时针对问题修订并再次看图，不能只凭 prompt 或生成成功就验收。
- 风格已获认可后，补内容或修科学细节采用局部编辑，保留配色、对象语言和整体密度。不能重新从零生成而退回稀疏方框、无色或公式堆叠的版本；需要改变整体风格时遵从用户的新要求。
- 图片存到当前项目工作区的合适位置，并保存实际使用的 prompt 与引用素材清单（路径、角色及输出文件）。这些用于复用，不把内部过程扩成长报告。
- PNG 是位图，不能称为逐元素可编辑 SVG。用户明确需要原生编辑时，选择匹配内容与画法的矢量或幻灯片工作流，实际检查可编辑性和渲染效果；不能把复杂插画退化成普通方块来满足格式。内嵌 PNG 的 SVG/PPT 不等于原生对象可编辑。
- 交付用户要求的最终图和必要的简短说明。仅报告实际完成的验证；如实区分单张样张的用户认可与跨论文效果验证，不把前者当作后者。
